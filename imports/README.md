# imports/

Hier legst du **deine eigenen Dateien** zum Importieren ab. Der Inhalt wird **nicht** in Git eingecheckt (siehe `.gitignore`), damit keine echten Familiendaten versehentlich veröffentlicht werden.

| Ordner | Inhalt |
|---|---|
| `gedcom/` | `.ged`-Dateien, z. B. MyHeritage-Export (Stammbaum → Exportieren → GEDCOM) |
| `json/` | Exporte im eigenen JSON-Format (Backups) |
| `_processed/` | bereits importierte Dateien (zur Ablage, optional) |

Beispieldateien zum Ausprobieren liegen in `../example/`.
