# Glossar

| Begriff | Bedeutung |
|---|---|
| Fokusperson | Person, um die die aktuelle Ansicht aufgebaut wird (früher „Ausgangsperson“) |
| Union | Partnerschaft zwischen zwei Personen (Ehe oder andere), besitzt Kinder |
| Vollgeschwister | gleiche Union, also beide Eltern gemeinsam |
| Halbgeschwister | nur ein gemeinsamer Elternteil |
| Stiefkind / Stiefelternteil | Verbindung nur über die Union, nicht über Abstammung |
| Ahnenschwund (pedigree collapse) | derselbe Vorfahre erscheint auf mehreren Wegen im Ahnenbaum |
| Geisterknoten | ausgegraute Referenz auf eine Person, die an anderer Stelle schon gezeichnet ist |
| Chunk | Teilgraph für eine Tiefe/Richtung, der gemeinsam geladen und gelayoutet wird |
| Culling | nur sichtbare Elemente zeichnen |
| LOD | Level of Detail, vereinfachte Darstellung beim Auszoomen |
| Belegt / Vermutet | `proven` / `assumed`: Beleg durch Quelle bzw. unbestätigt |
| GEDCOM | Standardaustauschformat für Genealogiedaten |
| Provider | Anbindung einer Online-Quelle (WikiTree, Wikidata, …) |
| Inzuchtkoeffizient | Maß, wie eng die Eltern einer Person verwandt waren |
